# Telegram ↔ Software Factory

Мост принимает задачи из личного чата Telegram, распознаёт голосовые сообщения через Groq и передаёт задачи в разговор **Software Factory Bot** (`bot-f94ac52a7fe2499692bb62b0dc0b5b07`). Когда бот выполнит задачу, его рабочая сессия отправит ответ или файл (например, APK) в тот же чат через `tg_send.py`. Ожидайте от моста «✅ Передал задачу» после приёма вебхуком; это не означает, что сама задача уже выполнена.

## Подготовка

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и сохраните токен как `TELEGRAM_BOT_TOKEN`. Откройте личный чат с новым ботом и нажмите **Start**.
2. Создайте ключ на [Groq Console](https://console.groq.com/keys) и сохраните как `GROQ_API_KEY`. Голосовые, аудио и видеосообщения-кружки транскрибируются моделью `whisper-large-v3` с автоопределением языка.
3. Настройте автоматизацию Devin с триггером `webhook:incoming`, которая проверяет `X-Webhook-Secret`. Запишите URL и секрет триггера как `DEVIN_WEBHOOK_URL` и `DEVIN_WEBHOOK_SECRET`. Настройте доставку сообщения **в разговор Software Factory Bot с указанным выше ID**, а не в отдельную сессию разработчика.
4. Укажите свой числовой ID в `TELEGRAM_OWNER_ID`. Если ID неизвестен, временно используйте `9007199254740991` (значение вне диапазона ID Telegram), запустите мост и отправьте `/id` в чат бота. Он покажет ваш ID, не пересылая сообщение в Devin. Замените временное значение своим ID и перезапустите мост. Можно указать несколько ID через запятую.

Храните токен и ключи в секретах окружения или в локальном `.env`, не отправляйте их в чат и не коммитьте. Секрет вебхука должен совпадать на обеих сторонах; для внешнего адреса используйте HTTPS.

## Настройка маршрута в Devin

Мост отправляет JSON с полями `source="telegram"`, `kind="text"|"voice"`, `chat_id`, `message_id`, `from` и `text`. Для документов и фото добавляется `attachments` с `file_id` и `file_name`. Это ссылки по ID внутри Telegram, а не копии файлов. Для голосового сообщения `text` содержит подпись (если она есть), затем транскрипт. Сам транскрипт также показывается в чате.

В автоматизации задайте фиксированного получателя — **Software Factory Bot** (`bot-f94ac52a7fe2499692bb62b0dc0b5b07`) — и передайте ему текст задачи, вложения (если есть) и числовые `chat_id` и `message_id`. Не выбирайте получателя из входящего JSON. Попросите бота передавать `chat_id` рабочей сессии и отправлять туда итоговый ответ и запрошенные файлы командой ниже. Дайте рабочим сессиям доступ к этому репозиторию и к секрету `TELEGRAM_BOT_TOKEN` **того же** Telegram-бота. Для исходящих сообщений другие ключи не нужны.

## Запуск

Локально или на VPS с Python 3.12:

```sh
cp .env.example .env
# Заполните .env
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python bridge.py
```

Либо через Docker (с заполненным `.env`):

```sh
docker build -t telegram-bridge .
docker run -d --name telegram-bridge --restart unless-stopped --env-file .env telegram-bridge
docker logs -f telegram-bridge
```

Команда запуска на хостинге: `python -u run.py`. Без `CHAT_BOT_TOKEN` запускается только мост. Если токен задан в окружении, в том же приложении запускается и чат-бот: при сбое каждый процесс перезапускается независимо. Оба получают сообщения через long polling: входящий порт открывать не нужно. Запускайте только один экземпляр на токен.

## Чат-бот с UnleashedAPI

Чтобы включить чат-бота в существующем приложении `tg-bridge` на Altare, создайте **другого** бота через [@BotFather](https://t.me/BotFather) и добавьте в окружение приложения:

- `CHAT_BOT_TOKEN` — токен нового бота, не `TELEGRAM_BOT_TOKEN` моста.
- `CHAT_BOT_NAME` — имя для обращения в чате (по умолчанию `Нори`).
- `CHAT_BOT_DB` — путь к SQLite-файлу с памятью (по умолчанию `.nori/chat-memory.sqlite3` в рабочем каталоге).
- `UNLEASHED_API_KEY` — ключ UnleashedAPI.
- `UNLEASHED_MODEL` — необязательный идентификатор модели (по умолчанию `deepseek-v4.1-flash-abliterated`).
- `KEENABLE_SEARCH_ENABLED=0` — отключает веб-поиск (по умолчанию включён).
- `KEENABLE_API_KEY` — необязательный ключ [Keenable](https://docs.keenable.ai/api-keys); без него используется публичный поиск.

Команда `python -u run.py` остаётся прежней. Если токен задан, а ключа UnleashedAPI ещё нет, чат-бот запишет предупреждение и завершится без перезапуска; мост продолжит работать. Для отдельного локального запуска можно задать переменные в `.env`, установить зависимости из `requirements.txt` и выполнить `python bot.py`.

В личном чате бот отвечает на любое сообщение. В группе он отвечает, если в сообщении есть его имя отдельным словом (например, «Нори, привет» или «Что думаешь, нори?»), его тег `@username`, команда `/nori вопрос` (или `/nori@username вопрос`) либо это ответ на сообщение бота. В остальных случаях он обычно запоминает текст молча. После 20 обычных сообщений без ответа бот с вероятностью 2% может сам коротко вступить в разговор, если увидит сообщение от 40 символов на знакомую тему (кино, музыка, игры и т. п.). Попытки — не чаще раза в час на группу и раза в 15 минут на все группы. Перед такой репликой бот проверяет границы; при запрете или сбое молчит. Веб-поиск не запускается; после ответа UnleashedAPI с кодом 429 бот на пять часов отключает инициативные реплики.

Нори запоминает, как человека зовут, чем он занимается и что ему нравится, по простым фразам от первого лица («Меня зовут Аня», «Работаю дизайнером», «Люблю джаз»). Для этого она не вызывает модель. Заметки (до 32 профилей на чат, 4096 на весь файл) хранятся в том же SQLite и не переходят в другие чаты. При ответе до восьми профилей могут попасть в контекст, чтобы Нори могла вспомнить сказанное к месту.

Нори понимает голосовые сообщения и фото. В группе подпишите фото обращением к Нори или ответьте на него с вопросом («Нори, объясни мем»). Чтобы задать вопрос голосом в группе, отправьте голосовое ответом на её сообщение или попросите Нори разобрать его ответом на это голосовое. Неадресованные фото и голосовые не скачиваются.

Распознавание использует уже настроенный `GROQ_API_KEY`: Whisper для речи и Qwen 3.8 для фото (модель фото можно заменить через `CHAT_BOT_VISION_MODEL`). Фото и аудио передаются Groq, их описание или расшифровка — UnleashedAPI. Они не отправляются в веб-поиск и отдельно не сохраняются в памяти; как обычно, там остаются текст обращения и ответ бота. Лимиты: фото до 2,9 МБ, голосовое до трёх минут и 8 МБ.

На своё голосовое можно получить голосовой ответ; для текстового вопроса используйте `/voice вопрос` (в группе также `/voice@username вопрос`). Ответы до 700 символов озвучиваются по-русски локально через [Piper](https://github.com/OHF-Voice/piper1-gpl) без ключей и оплаты. При первом голосовом бот скачивает [модель «Ирина»](https://huggingface.co/rhasspy/piper-voices/tree/613b6e5ad36ddca4e70e171957291483dc244d9f/ru/ru_RU/irina/medium) (63 МБ) в каталог `voice` рядом с SQLite. Длинные ответы и ответы при сбое синтеза отправляются текстом.

Чтобы Telegram передавал боту обычные сообщения группы, откройте [@BotFather](https://t.me/BotFather) → `/mybots` → выберите бота → **Bot Settings** → **Group Privacy** → **Turn off**, затем удалите и снова добавьте бота в группу. Другой вариант — назначить его администратором группы. Бот видит только новые сообщения, которые Telegram ему доставляет; старую переписку он не загружает.

Бот обращается к [Keenable](https://keenable.ai/) только когда ему адресовано сообщение, и пропускает поиск для простых приветствий, благодарностей и прощаний. В поиск отправляется только текст запроса, без истории чата. Keenable может сохранять поисковые запросы. До пяти результатов с заголовками, ссылками и выдержками передаются DeepSeek через UnleashedAPI для подготовки ответа. Бот просит модель не публиковать ссылки и отключает их предпросмотр. Если поиск не сработал или не ответил за 4 секунды, модель отвечает без результатов поиска. Пока готовится ответ, Telegram показывает «печатает…».

Бот локально проверяет адресованное сообщение и цитату на признаки нарушения семи жёстких правил. Если есть совпадение, DeepSeek оценивает запрос до поиска и отвечает коротким отказом при нарушении. Без совпадения поиск и генерация идут без отдельного API-вызова проверки; режим рассуждения выбирается локально по признакам логики, математики, кода или развёрнутого анализа. Перед отправкой бот также локально проверяет весь черновик, в том числе на признаки опасных инструкций и личные данные. Если есть совпадение, DeepSeek оценивает черновик вместе с запросом; при нарушении черновик не отправляется. Это эвристические проверки, не гарантия. Обычный ответ требует одного вызова DeepSeek, а срабатывание каждой из проверок добавляет один вызов. Все вызовы UnleashedAPI, включая пересказ, проходят через общую очередь с лимитом в два одновременных запроса на процесс. Если вызванная проверка вернула ошибку или не ответила за 5 секунд после отправки, бот пишет предупреждение в журнал и отправляет «Перегруз, попробуй через минуту.» вместо непроверенного ответа.

Для каждого чата бот хранит в SQLite 100 последних сообщений и ответов без сокращений (или все записи, если их меньше). Когда добавляются новые записи сверх лимита, бот отправляет только вытесненные старые записи в UnleashedAPI, чтобы обновить краткий пересказ. Если пересказ не обновился, вытесненные записи удаляются, а прежний пересказ сохраняется. При ответе модель получает недавние сообщения с именами авторов в группе, текст цитируемого сообщения (если он доступен) и пересказ. История не переносится между чатами; при запуске бот загружает её из того же файла. Для сохранения при перевыкладке задайте `CHAT_BOT_DB` внутри каталога, который хостинг сохраняет между выкладками (в Docker подключите том). Сохранность каталога по умолчанию при полной Git-перевыкладке на Altare не подтверждена. Предупредите участников группы, что сообщения могут передаваться в UnleashedAPI даже без обращения к боту, и не публикуйте секреты или персональные данные.

## Ответы и APK

Из рабочей сессии Software Factory Bot, используя `chat_id` именно этой задачи:

```sh
python tg_send.py --chat 123456789 --text "Готово, изменения проверены."
python tg_send.py --chat 123456789 --file ./app-release.apk --caption "Готовый APK"
```

Если опустить `--chat`, требуется `TELEGRAM_OWNER_ID`: берётся первый ID из списка. Длинный текст отправляется частями. APK приходит как документ; лимит загрузки через облачный Telegram Bot API — 50 МБ. Для большего файла можно отправить ссылку вместо документа.
